<h1>OpenWay</h1>
Проект разработанный командой ERROR 404 г. Новочеркасск для Хакатона DevHack 2026г. на базе IT-CUBE г. Ростова-на-Дону  

Представляет собой веб-приложение интерактивную карту призванную помочь людям с ОВЗ проще добираться до нужного места путём построения маршрутов через метки приспособлений созданных для людей с инвалидностью.  

<h3>Стек и технологии</h3>
Приложение выполнено на языке Python при помощи модуля Streamlit.
В приложении используются следующие API и инструменты: 
<ul>
  <li>OpenStreetMap, Overpass API, Openrouteservice, GeoPy, Folium - для просмотра и навигации по карте, а также построения маршрутов</li>
  <li>Yandex Weather API - погода Яндекс расположенная в Sidebar-е приложения для простоты выбора пользователем одежды при настоящих погодных условиях</li>
  <li>Sber GigaChat API - ИИ Sber для генерации советов пользователю основывающихся на погоде в настоящее время</li>
</ul>  

[Ссылка на удаленный адрес с приложением](https://openway.streamlit.app)
